HabitPulse Pro PWA files

For GitHub Pages:
1. Create a PUBLIC repository named habitpulse.
2. Upload every file and folder in this package to the repository root.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site. Open the published HTTPS address in Chrome on Android.
7. In Chrome, open ⋮ and choose Install app (or Add to Home screen).

Keep all files and folders in their original structure. Do not upload this ZIP file by itself; extract it first and upload index.html, manifest.json, sw.js, and the icons folder.
